DittoAndroidTools 6 supports Ditto Kotlin SDK 5 and requires `com.ditto:ditto-kotlin` 5.0.1 or a later 5.x release.

## Breaking changes

- Install the tools from `com.ditto:ditto-tools-android` and update tools imports from `live.ditto.tools.*` to `com.ditto.tools.*`.
- Migrate DittoAndroidTools to Ditto Kotlin SDK v5 by @kristopherjohnson in https://github.com/getditto/DittoAndroidTools/pull/170. Ditto Kotlin SDK 4 is no longer supported; the SDK dependency is now `com.ditto:ditto-kotlin`, and SDK imports use `com.ditto.kotlin.*`.
- The minimum Android API level increased from 23 to 24. The standalone project now compiles against Android API 36.
- Ditto initialization, observers, subscriptions, store values, and exception types use the SDK 5 APIs.
- Presence Degradation conversion extensions now receive `DittoCborSerializable.Dictionary` instead of the SDK 4 `DittoDocument` type.
- Disk Usage uses `DittoDiskUsageItem` instead of `DiskUsageItem`; `DiskUsage.sizeInBytes` and `DiskUsageState.totalSizeInBytes` are now `Long` values.
- Heartbeat `addToCollection` is now a suspending function because its SDK 5 DQL write is asynchronous.
- `DittoHeartbeatInfo.peerKeyString` was renamed to `peerKey`, aligning Android Tools with the other platforms and the Ditto 5 peer API. The heartbeat document key remains `peerKey`.
- The Data Browser document filter field now accepts DQL `WHERE` expressions such as `title = 'Hello, World!'`.
- Data Browser implementation types and composables are now internal. Use `DittoDataBrowser(ditto)` as the public entry point.
- The Data Browser no longer creates sync subscriptions. It displays only data already present in the local store; the host application remains responsible for syncing data.

## Public API changes

- Heartbeat documents add a `connectionTypes` map containing every observed SDK connection type. The existing `bluetooth`, `p2pWifi`, and `lan` summary fields remain available.

## Added

- Logviewer by @jperalta-ditto in https://github.com/getditto/DittoAndroidTools/pull/169. It adds file selection, tailing, filtering, log-level display, details, and scroll controls.
- Presence Viewer displays Multicast Beta connections in the graph and legend. (SDKS-4556)

## Fixed

- Fixed Data Browser collection discovery, DQL collection-name quoting, CBOR map and list display, stale document selection, and visible errors for filters and document loading.
- Fixed leaked observers, log-path handling, disk-usage path display, and Heartbeat serialization during the v5 migration.
- Fixed Heartbeat and the Presence Degradation Reporter incorrectly counting WebSocket connections as LAN.
- Fixed Presence Viewer edge-label colors changing with the browser's dark-mode preference.
